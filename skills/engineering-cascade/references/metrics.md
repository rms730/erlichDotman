# Metrics

Record task completion/first pass, attempts, tiers, reasoning controls when exposed, input/output tokens, metered usage/unit, cost/currency, latency, validation, escalations, changed files, observed defects/rework and interventions. Include every planning/implementation/retry/review leg.

Unknown values are `null`. Context estimates, synthetic fixtures and guessed prices cannot become measured savings. Aggregate compatible complete measurements; retain coverage when partial. Cost/tokens per successful task includes costs of failed tasks and retries. Interim planning legs do not count as completed tasks.

Use held-out repeated trials and frozen baselines. Recommend reviewable changes only after enough measured evidence; never learn real-model defaults from scripted fixture choices. Avoid invented engineering-value precision: acceptance, task importance and observed rework are separate, transparent measures.
