# Routing

Tier 0 resolves uncertainty with tools and no inference. Tier 1 fits specified mechanical work. Tier 2 fits ordinary implementation and review. Tier 3 fits architecture, unfamiliar systems and difficult debugging. Tier 4 fits critical/irreversible decisions where additional reasoning may increase success.

Classify the next stage, not the whole project forever. Complexity, ambiguity, security, production consequences, distributed state and cross-repository dependencies justify floors. A precise implementation packet can remove ambiguity; it cannot remove the consequences of a migration. Keep risk floors after a downgrade.

The CLI's explicit bootstrap policy is uncalibrated. Select the least expensive credible method, not the cheapest nominal token price. Failed attempts, latency, attention and rework count. Only measured engineering trials can support future cost-optimized defaults.
