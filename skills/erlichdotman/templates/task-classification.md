# Task classification

- Project / task / fresh revision:
- Objective and acceptance:
- Category / next engineering stage:
- Complexity / ambiguity / risk, with concrete evidence:
- Consequential signals (security, irreversible, distributed, unfamiliar, production, cross-repository):
- Deterministic operation that could resolve uncertainty:
- Mechanical work already specified:
- Required capabilities and minimal installed skills:
- Required context estimate / budget:
- Tier recommendation / actual runtime controls available:
- Validation commands / escalation evidence / attempt limit:

Use concise values and evidence, not a long justification.
