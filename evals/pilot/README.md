# Exploratory orchestration pilot kit

This optional kit tests whether ErlichDotman's incremental effect can be measured. It neither runs models nor establishes savings. Keep completed manifests and raw project evidence in ignored `.cascade/` or `evals/results/`; committed examples are generic templates.

1. Read [the protocol](PROTOCOL.md) for this explicit evaluation task.
2. Copy [the draft preregistration](preregistration.template.json) to private state; fill task specs, baseline, controls, budgets and graders before freezing it.
3. Use [one compact stage entry](stage-entry.template.json) per actual workflow leg/boundary; reconcile it to host traces and capture overhead. It is a proposed experimental format, not a current CLI contract.
4. Report technical evidence and coverage; use [the status template](STATUS_PAGE.template.md) for a concise user-facing view.

See [implementation priorities](../../docs/IMPROVEMENT_PLAN.md) for what is ready and what still needs tooling. Do not load this kit during normal implementation handoffs.
