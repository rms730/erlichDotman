# Context-disclosure forward tests

These synthetic dry-run requests test instruction ownership and progressive disclosure. They are separate from code-routing and scripted-fixture evals. Give an independent host agent the case requests and only the applicable raw entrypoints/artifacts; do not provide intended answers or the audit conclusions. Record its chosen reads, decisions, worker payload and unresolved facts here as reviewed evidence, not raw private traces.

Assess observable behavior: necessary acceptance facts survive; current code defeats stale summaries; unsupported controls remain unknown; scope/provenance do not grant permission; worker context stays project-bound; optional documents are read only for a task-specific need. A proposal to read every guide does not pass just because it is safe.

This is a behavioral smoke test, not a measured quality/resource benchmark. No token savings or engineering completion rate follows from an agent's explanation of its intended reads. The next experiment needs held-out completed tasks, actual host read/usage traces and all-leg resource/rework accounting.
